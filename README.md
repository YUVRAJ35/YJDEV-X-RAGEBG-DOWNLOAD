# 🎮 YJDEV × RAGE BG Gaming Hub

**Your Gaming. Your Mods. Your Community.**

A Minecraft-first gaming hub built by **YJDEV STUDIOS × RAGE BG**, designed to bring mods, modpacks, shaders, resource packs, server discovery, and gaming community features into one desktop application.

> 🚧 **Status: Early Beta — v0.1.0**
>
> The project is under active development. Some features may be incomplete, and bugs are expected. Check the latest release notes for updates.

---

## ✨ Features

- 🏠 **Gaming Dashboard** — Access the hub's main features from one place.
- 🧩 **Mods** — Discover gaming modifications.
- 📦 **Modpacks** — Explore modpack collections.
- 🌈 **Shaders** — Find shader packs for supported games.
- 🎨 **Resource Packs** — Discover Minecraft resource packs.
- 🌐 **Server Listings** — Browse community server listings and add servers.
- 🏆 **Leaderboards** — View available player-level and server rankings.
- 👤 **Accounts** — Login and sign-up interface.
- 👻 **Ghost AI** — An experimental in-app assistant.
- 💎 **Plans** — Preview planned YJDEV+ membership tiers.
- 🔗 **Community Links** — Access official websites and community channels.

*Feature availability may vary by version. Some features are experimental or still being developed.*

## 🛠️ Development Setup

Want to explore or contribute to the project?

### Requirements

- Node.js and npm
- Git
- Windows for testing the Windows desktop build

### Run locally

1. Clone the repository containing the application source code.
2. Open a terminal in the project directory.
3. Install the dependencies.
4. Start the development environment using the project's documented scripts.

